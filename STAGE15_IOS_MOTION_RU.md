# VANTA Stage 15 — iOS-style interactive motion

Основан на Stage 14. ExoPlayer, очередь, эквалайзер, аудиовыходы, БД, версии Gradle/Kotlin/Compose и зависимости не менялись.

## Главная идея
Раньше анимации были «запустил и забыл». Теперь ключевые движения следуют за пальцем, их можно перехватить на середине, а после отпускания пружина подхватывает скорость жеста.

## Что изменено

- `ui/nav/VantaNav.kt` — Now Playing стал шторкой на одном значении `progress` (0..1).
  - Тянется за пальцем вниз, отпускание с учётом скорости (fling).
  - Home остаётся под шторкой: уменьшается, скругляется и затемняется, сохраняет позицию списка.
  - Predictive back (жест «назад» плавно сдвигает шторку).
  - Анимацию можно прервать касанием.
- `ui/player/NowPlayingScreen.kt`
  - Свайп трека: карточка (обложка + название) едет за пальцем, вылетает и новый трек плавно въезжает с нужной стороны. Кнопки Prev/Next тоже въезжают с соответствующей стороны.
  - Ползунок перемотки утолщается при касании, прогресс идёт плавно между обновлениями позиции.
  - Prev/Next/Shuffle/Repeat получили press-scale.
- `ui/components/MiniPlayer.kt` — перетаскивание с учётом скорости, резинка вверх, свайп вверх открывает плеер, свайп вниз закрывает; пружинный возврат.
- `ui/home/HomeScreen.kt`
  - Контент вкладок переключается со сдвигом и fade в сторону выбранной вкладки; добавлен свайп между вкладками.
  - `animateItem()` для строк треков и карточек альбомов (плавные вставки/удаления/перестановки).
  - Мини-плеер появляется/исчезает пружиной.
- `ui/components/GlassTabBar.kt` — индикатор с лёгким «жидким» перелётом, цвет текста анимируется, вес шрифта постоянный (нет скачка).
- `ui/components/Anim.kt` — новый `PressIconButton`.
- `ui/motion/VantaMotion.kt` — `SheetOpenSpring`, `SheetCloseSpring`, `ReleaseSpring`.
- `AndroidManifest.xml` — `enableOnBackInvokedCallback="true"` для predictive back.

## Не проверено
Gradle Wrapper в проекте по-прежнему нет, сборка в этой среде не запускалась. Код проверен только на баланс скобок и по API Compose BOM 2024.12.01 (foundation 1.7: `animateItem`, `draggable`, `PredictiveBackHandler` из activity-compose 1.9.3). Если Android Studio покажет ошибки компиляции, пришли текст ошибки.

- Собственная физика для `ModalBottomSheet` (очередь, эквалайзер).
