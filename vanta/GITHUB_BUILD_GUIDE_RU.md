# Сборка VANTA APK через GitHub Actions (без компьютера)

## 1. Создай репозиторий
1. Открой https://github.com и войди в аккаунт.
2. Нажми **+** → **New repository**.
3. Назови репозиторий `VANTA`, выбери **Private** или **Public**.
4. Нажми **Create repository**. Не добавляй README, `.gitignore` или License, потому что они уже есть в проекте.

## 2. Загрузи проект с телефона
1. Распакуй архив `vanta-github-build.zip` в файловом менеджере телефона.
2. Открой созданный репозиторий на GitHub в браузере.
3. Нажми **Add file** → **Upload files**.
4. Загрузи ВСЁ содержимое папки `vanta` (не сам ZIP и не вложенную папку `vanta` целиком, если GitHub предлагает загрузить её как один файл).
5. Убедись, что в корне репозитория видны `settings.gradle.kts`, `build.gradle.kts`, папки `app`, `core`, `data`, `player`, `gradle` и `.github`.
6. Внизу нажми **Commit changes**.

Важно: GitHub web uploader может быть неудобен для большого количества файлов на телефоне. Если браузер не позволяет загрузить папки целиком, включи «Версия для ПК» или загружай файлы партиями, сохраняя структуру каталогов. Файл workflow должен оказаться именно по пути `.github/workflows/android.yml`.

## 3. Запусти сборку
1. В репозитории открой вкладку **Actions**.
2. Выбери workflow **Build VANTA APK**.
3. Если сборка после загрузки кода не запустилась автоматически, нажми **Run workflow** → **Run workflow**.
4. Открой появившийся запуск и дождись завершения задания `Build debug APK`.

## 4. Скачай APK
1. В завершённом запуске найди раздел **Artifacts**.
2. Скачай `VANTA-debug-apk`.
3. Распакуй скачанный ZIP. Внутри будет `app-debug.apk`.
4. Открой APK на Android и разреши установку из этого источника, если система попросит.

## Если сборка упала
Открой запуск в **Actions**, раскрой красный шаг и скопируй полный текст ошибки. Пришли его разработчику. Не присылай токены, пароли или секретные ключи GitHub.

## Текущее состояние
Это debug-сборка интерфейса VANTA с тестовыми данными и имитацией управления плеером. Она не является релизной версией и пока не реализует полноценное воспроизведение локальной музыкальной библиотеки. Установка APK не означает, что все функции уже готовы.
