# VANTA Stage 13 — Library scrolling & motion

## Исправления

- `HomeScreen.kt`: добавлены `contentType` для элементов треков, альбомов, артистов и плейлистов, чтобы Lazy layouts могли эффективнее повторно использовать композиции.
- `HomeScreen.kt`: удалён `animateItem()` у каждой строки трека. Постоянная анимация размещения не нужна для обычной прокрутки и может создавать лишнюю работу при изменениях списка.
- `HomeScreen.kt`: создан индекс `trackById` и предварительно рассчитано число доступных треков плейлистов. Раньше каждая видимая строка плейлиста линейно искала каждый ID по полной библиотеке.
- `HomeScreen.kt`: список названий вкладок запоминается, а не создаётся заново при каждой композиции.
- `TrackRow.kt`: текст подзаголовка кэшируется через `remember`, пока не меняются исполнитель и альбом.
- `GlassTabBar.kt`: индикатор вкладки теперь сохраняет постоянный размер и перемещается через `graphicsLayer`. Это убирает изменение ширины и повторные layout-измерения на каждом кадре анимации.

## Совместимость

Проект использует Kotlin 2.1.0, AGP 8.7.3 и Compose BOM 2024.12.01. Изменения используют существующие Compose API и не добавляют зависимости. ExoPlayer, очередь, эквалайзер, аудиовыходы и разрешения не менялись.

## Проверка

Архив исходников проверен на целостность. Полную Gradle-сборку в этой среде выполнить нельзя: в исходном архиве отсутствуют `gradlew` и `gradle-wrapper.jar`, а системная команда `gradle` недоступна. Поэтому APK не заявляется как собранный или протестированный.
