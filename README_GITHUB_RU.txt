VANTA: сборка APK без компьютера

1) Прочитай GITHUB_BUILD_GUIDE_RU.md.
2) Загрузи содержимое этой папки в корень нового GitHub-репозитория.
3) Открой Actions и запусти Build VANTA APK.
4) Скачай Artifact VANTA-debug-apk и распакуй его.
5) Установи app-debug.apk на Android.

Сборка выполняется в GitHub Actions. В проекте пока нет Gradle Wrapper JAR, поэтому workflow устанавливает Gradle 8.9 в облачной среде и запускает его напрямую.

Это тестовый UI-прототип, а не готовый музыкальный плеер. Воспроизведение и сканирование библиотеки ещё требуют реализации.
